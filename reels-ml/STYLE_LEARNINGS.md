# Style learnings from the user's reference illustrations (2026-11-11). Reference scenes are NOT copied; only the principles are used.
What the references do well, and how we apply it with code:
1. The SETTING tells the story: every object is specific to the scene. Rule: build sets only from what the script needs (a money story: pinboard of goals, laptop with charts, piggy bank, planner), never generic filler.
2. LIGHT and SHADOW: warm directional light, light patches on floor and wall, soft shadows. Applied: window light shafts (gradient polygons), lamp glow (radial gradient), floor light patch, vignette. No blur or glow filters.
3. TEXTURE: soft grain instead of clean flat fills. Applied: a static noise tile overlay that shifts every frame (film grain).
4. LAYERED DEPTH: far / mid / near layers with different camera parallax; foreground objects (plants, desk, mug) overlap the subject.
5. NATURAL ANGLES: 3/4 view, back-of-head, over-the-shoulder. Applied: Ramu 3/4 head (face34), back view (headBack), turn from 3/4 to front with a squash.
6. DETAILED SMALL PROPS: scissors/tape/bag in the reference; ours: mug with steam, notebook and pen, keyboard keys, sticky notes, washi tape, piggy bank.
Limits: code-built shapes cannot match hand-painted brushwork; expect "textured, shaded vector". Hiring an illustrator for the character sheet and key sets remains the highest-quality option.
