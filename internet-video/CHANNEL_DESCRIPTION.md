# WHAT IF: channel description (YouTube "About", max 1,000 characters)

## Main version
What if the internet disappeared tomorrow? What if the world ran out of something we take for granted?

WHAT IF explores big, strange "what if" scenarios and follows them step by step: the first hour, the first day, the first year. Each video is a short animated story built on real examples and sourced facts, so you get the curiosity without the hype.

Expect:
• Clear, calm explanations, no clickbait
• Real events behind every scenario
• Simple animation you can follow in about 5 minutes
